ระบบตอบคำถามวิชาการ (Auto-Discovery Model)

Knowledge Base: 219 Papers

สวัสดีครับทันตแพทย์ประจำบ้าน / ผู้เตรียมสอบวุฒิบัตรฯ

ระบบนี้ได้รับการแก้ปัญหาเรื่อง Model Name เรียบร้อยแล้ว ด้วยระบบ Auto-Discovery

เมื่อคุณใส่ API Key ระบบจะวิ่งไปถาม Google ให้อัตโนมัติว่า Key ของคุณสามารถใช้โมเดลชื่ออะไรได้บ้าง (เช่น gemini-1.5-flash, gemini-2.0-flash, หรือ gemini-3.6-flash) และจะดึงตัวที่ดีที่สุดมาตอบให้ทันที ทำให้ไม่มีปัญหา Model Not Found อีกต่อไปครับ!
